音乐下载器

音乐搜索、下载、本地播放、歌单整理与双语同步歌词，集中在一个桌面工具里。

下载 Windows 版 ↗查看源码 ↗
功能与使用说明

支持本地歌单、同步歌词、桌面歌词和沉浸播放。桌面歌词需要在程序内手动开启。

点击下载入口会前往 GitHub 最新发布页，确认版本后选择便携 EXE。不会在本站自动下载或安装。

具体功能和系统要求以项目说明为准。
