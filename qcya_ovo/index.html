写给过去的自己

最开始做这个网站的时候，连页面布局都在摸索。虽然它只是一个半成品，但它确实承载了第一次让网页运行起来的快乐。

所以这次改版，继续保留了当年的图片素材，也保留了那份“想做个自己的主页”的心情。

  1. THEN

    第一次写网页

    从简单的 HTML 和 CSS 开始，拼出属于自己的那张小卡片。

  2. ALONG THE WAY

    越来越多的奇怪点子

    视频、脚本、工具、游戏……想做的东西越来越多。

  3. NOW

    新页面，新起点

    让它成为真正能展示创作和记录成长的个人空间。
